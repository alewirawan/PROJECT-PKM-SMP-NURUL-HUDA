PERTAMA KALI

1. Install Git dan Docker Desktop. Buka Docker Desktop sampai engine siap.
2. Clone repository atau buka folder project yang sudah ada:
   https://github.com/alewirawan/PROJECT-PKM-SMP-NURUL-HUDA
3. Gunakan terminal di folder berisi compose.dev.yaml, frontend, dan backend.
   Windows: gunakan CMD, simpan project di luar OneDrive.
4. Jika belum ada, salin backend/.env.example menjadi backend/.env.
   Isi POSTGRES_PASSWORD. Jangan menimpa .env atau password database lama.
5. Jalankan:
   docker compose --env-file backend/.env -f compose.dev.yaml up --build -d --wait
6. Periksa:
   docker compose --env-file backend/.env -f compose.dev.yaml ps
   postgres, backend, frontend harus Up (healthy).
7. Buat akun admin sekali:
   docker compose --env-file backend/.env -f compose.dev.yaml run --rm backend npm run admin:create --workspace=@nurul-huda/backend
   Ikuti pertanyaan terminal. Password minimal 12 karakter dan tidak tampil saat diketik.
8. Buka http://localhost:3000 dan http://localhost:3000/admin.

JALANKAN LAGI

Buka Docker Desktop dan terminal di root project:
   docker compose --env-file backend/.env -f compose.dev.yaml up -d --wait

BERHENTI
   docker compose --env-file backend/.env -f compose.dev.yaml stop

SETELAH PULL
Simpan/commit pekerjaan sendiri dahulu; ikuti alur branch pada panduan lengkap.
Setelah mengambil update:
   docker compose --env-file backend/.env -f compose.dev.yaml up --build -d --force-recreate --wait

JIKA GAGAL
   docker compose --env-file backend/.env -f compose.dev.yaml ps -a
   docker compose --env-file backend/.env -f compose.dev.yaml logs --tail=80 postgres backend frontend
